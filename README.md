# 🚶 서울 시민은 어떤 길을 '걷기 좋다'고 느낄까?

## 1. 주제
길 찾기 앱은 '가장 빠른 길'만 알려 주지만, 사람들은 '걷기 좋은 길'을 고르기도 합니다.
이 연구는 **보도 너비, 차선 수, 횡단보도, 상업지역, CCTV 같은 도로의 특징이
시민이 느끼는 걷기 만족도와 어떤 관계가 있는지** 공공데이터로 분석합니다.

### 가설
1. 보도가 넓을수록 만족도가 높을 것이다.
2. 차선이 많은 길일수록 만족도가 낮을 것이다.
3. 상업지역은 만족도가 높을 것이다.
4. CCTV가 많은 길은 만족도가 높을 것이다.

## 2. 데이터 출처
| 데이터 | 출처 | 용도 |
|---|---|---|
| 서울시 유동인구 조사 – 속성조사 2015 | 서울 열린데이터광장 [OA-21706](https://data.seoul.go.kr/dataList/OA-21706/F/1/datasetView.do) | 시민 20,000명의 보행환경 만족도 (결과 y) |
| 서울시 유동인구 조사 – 조사지점정보 2015 | 서울 열린데이터광장 [OA-21707](https://data.seoul.go.kr/dataList/OA-21707/F/1/datasetView.do) | 지점 위치, 보도너비, 차선 수, 횡단보도, 용도지역 (요인 x) |
| CCTV 설치 현황 (서울 25개 구) | 공공데이터포털 | 반경 100m 안 CCTV 대수 |

| 교차로 정보 (신호정보) | 공공데이터포털 (한국지방행정연구원) | 반경 100m 안 신호 교차로 수 |

※ 유동인구 조사 자료는 공공누리 제4유형(출처표시, 상업적 이용 금지, 변경 금지)입니다.

## 3. 분석 방법
1. **데이터 점검**: 만족도 글자 → 1~5점 변환, 중복 지점 제거, 좌표 없는 4곳 제외, 버스정류장·지하철 칸 98.6% 일치 → 하나로 합침, TM좌표(EPSG:5181) → 위도·경도 변환
2. **지점별 평균**: 1,000개 지점 × 20명 → 지점별 평균 만족도 (최종 996곳)
3. **탐색**: 지도, 구별 평균, 요인별 그룹 비교·산점도
4. **다중 선형회귀** (statsmodels OLS): `만족도 = b0 + b1×보도너비 + … + 구별 차이`

## 4. 주요 결과
- 상업지역이면 만족도 **+0.19점** (p < 0.001) → 가설 3 지지
- 보도 1m 넓을수록 **−0.02점** (p ≈ 0.01) → 가설 1과 반대 (큰길 효과로 추정)
- 차선 수, CCTV, 계단, 횡단보도, 펜스는 뚜렷한 관계 없음
- 길 특징만: R² = 0.02 / 구 차이 포함: R² = 0.15 → 동네 차이가 더 큼
- 한계: 연관 관계이지 원인 아님, 설문(2015)과 CCTV 등(최근)의 시점 차이
